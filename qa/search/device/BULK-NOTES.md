# 다중 선택 기능

사용: 우측 상단 ⋮ → 다중 선택 → 카드/체크박스로 선택 → ⋮ → 폴더 이동 / 선택 삭제 / 선택 공유.
선택 완료 또는 뒤로 가기로 종료. 전체 선택/해제는 현재 보이는 결과에만 적용.
폴더 변경 시 선택 해제. 화면 재생성 시 선택 유지.
공유 내용은 제목과 URL이며 메모는 포함하지 않음. 공유 앱/수신자는 사용자가 선택.

일괄 DB 작업은 트랜잭션으로 처리하며 SQLite 변수 제한을 피하도록 500개씩 처리.
이동 대상 폴더가 삭제되었으면 실패 처리. DB 스키마 변경 없음.
실사용 Play 앱과 데이터는 건드리지 않고 별도 .searchtest 패키지로 검증.

검증:
- 1001개 이동/삭제, 미선택 항목 보존, 제목·메모 보존, 없는 폴더 이동 실패, 공유 텍스트 구성
- Galaxy S25 Ultra: 선택/재생성/이동/전체 선택/삭제 취소/삭제 완료
- 제목·메모 및 검색 회귀 테스트
- UI 증거: bulk-selection.png
- APK: DWBookMark-bulk-test.apk ('DWBookMark 검색 테스트' 설치 업데이트)
- 실제 수신자에게 공유 전송은 수행하지 않음.
- 스토어 출시/버전 번호 변경은 수행하지 않음.
