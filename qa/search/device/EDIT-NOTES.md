# 제목 수정 및 메모 기능 검증

- 사용: 북마크 카드를 길게 누르기 → 제목·메모 수정 → 저장.
- 카드에 메모를 최대 2줄 표시하며, 편집 창에서 전체 내용을 볼 수 있음.
- 검색 범위: 제목, URL, 메모. 기존 폴더 필터 유지.
- Room DB 1/2 → 3 마이그레이션에서 기존 제목, URL, 폴더, 정렬 보존.
- 백업 형식 2에 메모/사용자 제목 수정 여부 포함. 이전 형식 1 가져오기 지원.
- 새 백업을 구버전 앱에서 복원하려면 앱 업데이트 필요.
- 늦은 메타데이터 갱신과 정렬 저장이 사용자 제목/메모를 덮어쓰지 않음.
